# FairSight Backend

This is the FastAPI-powered backend for the FairSight AI Bias Audit Tool.

## 🚀 Getting Started

1. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   .\venv\Scripts\activate  # Windows
   source venv/bin/activate # Unix/macOS
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the server:
   ```bash
   python main.py
   ```

## 🛠 Tech Stack
- **FastAPI**
- **Pandas**
- **Fairlearn**
- **Scikit-learn**
