# FairSight Frontend

This is the React-based dashboard for the FairSight AI Bias Audit Tool.

## 🚀 Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

## 🛠 Tech Stack
- **React 19**
- **Vite**
- **Recharts**
- **Lucide Icons**
- **Axios**

Refer to the [main README](../README.md) for full project details.
